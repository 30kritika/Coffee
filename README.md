SipSavvy Cafe Web app ☕

A sleek and user-friendly web application for Sipsavvy Café, designed to enhance the customer experience with an intuitive interface and seamless navigation.

##Features
-> Responsive Design: works smoothly across devices
-> Meny Showcase- display cafe offerings attractively
-> Location and Contact Info: Provides essential details for visitors

##Future Scope
-> Online Ordering System: to allow customers to place orders digitally
-> User Accounts and Loyalty Program- enhancing customer engagement
-> Interactive Meny Customization: Personalized food choices

##Tech Stack
-> Frontend: ReactJS, HTML, CSS, JavaScript
-> Styling: Tailwind CSS, Motion Frame
-> Deployment: Netlify

##Live Demo
Check out the live version here: https://sipsavvycafe.netlify.app/
